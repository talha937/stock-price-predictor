Features

Built to be useful and honest

A small end-to-end machine learning project, from raw prices to a tested model behind a web page.

Next-day lean

See whether the model expects tomorrow's move to be above or below the stock's usual daily drift.

Honest accuracy

Every result sits next to a coin flip and a simple always-up guess, so you can judge it fairly.

Trained per stock

Each ticker gets its own model, built from its own history with returns, trends, volatility, RSI and MACD.

Tested properly

Time-ordered splits, walk-forward testing and a backtest with trading costs, with no peeking at the future.

How it works

From ticker to lean in four steps

It usually takes a few seconds the first time you check a stock.

  1. Pick a ticker

    Type a symbol like AAPL or choose a quick pick.

  2. Load the history

    Daily prices are downloaded and cleaned for that stock.

  3. Train the model

    A Random Forest learns from past indicators and next-day returns.

  4. Read the lean

    Check the verdict, then the trust meter to see how much it counts for.

FAQ

Questions people ask

Short answers about what this tool can and can't do.

What does "leans up" mean?

The model predicts tomorrow's return and compares it with the stock's average daily return in its history. If the prediction is higher, it leans up. If lower, it leans down.

How accurate is it?

In walk-forward testing from 2023 to 2026, it picked the right direction about 52.6% of the time. A coin flip gets 50%, and always guessing up got 54.6%. So it is a weak hint, not a reliable signal.

Is this financial advice?

No. It is a learning project that shows how to build and test a model without leaking future data. Please don't trade on it.

Why does the first check take a few seconds?

The app downloads the stock's history and trains a fresh model. After that, the result is kept for an hour so repeat checks are instant.

Which stocks work?

Any ticker with enough daily price history on Yahoo Finance. Very new listings may not have enough data.

StockLean is an educational project. Nothing here is investment advice, and past performance does not predict future results.

The model uses only past prices and simple indicators, and in testing it did not beat basic guesses.
